# 📚 Library Management System

A CakePHP-based Library Management System built using MVC architecture and MySQL database integration.


## 🚀 Features

* Add new books
* Edit existing books
* Delete books
* View all books
* Database integration
* MVC architecture
* Form validation
* Dynamic table rendering


## 🛠 Tech Stack

* CakePHP
* PHP
* MySQL
* HTML5
* CSS3


## 🧠 Architecture

This project follows the MVC (Model-View-Controller) pattern using the CakePHP framework.

### Components Used

* Controllers
* Models
* Templates/Views
* Routing
* Database ORM
